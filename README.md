## 🚀 Getting Started

1. Clone this repository:
   ```bash
   git clone https://github.com/yourusername/node-js-mastery.git
   ```

2. Navigate to the project directory:
   ```bash
   cd node-js-mastery
   ```

3. Install dependencies:
   ```bash
   npm install
   ```

4. Start the server:
   ```bash
   node index.js
   ```

5. Open your browser and visit:
   ```
   http://localhost:3000
   ```
